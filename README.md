# AX 2027 실행 로드맵

AX를 추진하는 기업이 2027년에 지켜야 할 마일스톤과, AI 교육·워크숍 서비스의 차별화 전략(타깃, 포지셔닝, 가격)을 제안하는 컨설팅 브리프입니다.

- `index.html`: 보고서 페이지. 공개 조사 3종(McKinsey, Microsoft·LinkedIn, BCG)의 탐색적 분석과 도표 8개
- `ax-2027-explainer.webm`: 60초 설명 영상 (1280×720, 한국어 음성·자막, 키네틱 타이포와 라인 아트)
- `video-source/`: 영상을 렌더링한 페이지와 문장별 내레이션 음성

보고서의 가격과 마일스톤 목표값은 시장 조사 값이 아니라 제안안입니다.
